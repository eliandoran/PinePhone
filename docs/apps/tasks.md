# Tasks

Tasks is a list of things to do, which you tick off as you do them.

![Three tasks to do and two done](../images/generated/tasks-list.webp){ width="300" }

The tasks to do come first, in the order you added them. Below them, under **Done**, are the
ones you ticked off, the most recent first.

## Add a task

1. Tap **New task** at the bottom. The keyboard comes up.
2. Type the task.
3. Press Enter on the keyboard, or tap the :fontawesome-solid-plus: plus button beside the field.

![A task being typed](../images/generated/tasks-new.webp){ width="300" }

The keyboard stays up, so you can type the next task right away. When you are done, hide it
with its :fontawesome-solid-keyboard: keyboard key.

## Tick off a task

Tap a task: its circle fills with a :fontawesome-solid-check: check mark and it moves down to
**Done**. Tapped again, it goes back among the tasks to do, in its place.

Tasks stay on the phone when it restarts and when its software is updated. There are no due
dates or reminders yet, and a task cannot be changed or deleted yet.
