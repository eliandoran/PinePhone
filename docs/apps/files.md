# Files

Files lets you look through the files on the phone: what is in a folder, how big a file is,
when it was changed, and the start of a text file. It only shows them: it cannot delete,
rename, copy or open files in other apps.

## Browsing

Open **Files** from the menu (under **Tools**). It starts at the top of the phone's file
system, the screen titled **Files**.

1. Tap a folder to open it. Its name becomes the title of the screen.
2. Tap the back arrow at the top left to go up one folder.

Folders come first, with a blue folder symbol and an arrow, then the files, each in
alphabetical order. Each file shows a symbol for its kind (picture, sound, video, text or
other), its size and when it was last changed: the time for today, the day of the week for
the past few days, otherwise the date.

![The photos folder](../images/generated/files-folder.png){ width="300" }

What the apps save is in **var › lib**:

| Folder | What is in it |
|---|---|
| **photos** | photos and screenshots ([Gallery](gallery.md)) |
| **music** | the songs [Music](music.md) plays |
| **memos** | voice memos ([Recorder](recorder.md)) |
| **notes** | notes ([Notes](notes.md)) |

A folder with nothing in it says **Empty folder**; one you are not allowed to look into says
**Cannot open this folder**. A folder shows at most 500 entries; under them, a line says how
many more there are (**3 more not shown**).

## A file's details

Tap a file. Its screen shows:

- **Size**, **Modified** (as in the list) and **Folder**, the folder it is in;
- for a text file, the start of it: up to 40 lines, or about 2,000 characters.
