# Notes

Notes keeps short texts on the phone: shopping lists, ideas, things to remember. Each
note's first line is its title.

![Three notes, the newest first](../images/generated/notes-list.png){ width="300" }

The list shows the newest notes first (the last changed). Each row has the title, when the
note was last changed (the time for today, the weekday for the last few days, the date
before that) and the start of the rest of the text.

## Write a note

1. Tap **+** at the top right. A **New note** opens with the keyboard.
2. Type the title on the first line, then the rest of the note.
3. Tap the back arrow at the top left.

![A new note being typed](../images/generated/notes-new.png){ width="300" }

There is no save button: the note is saved when you go back, and also when you hide the
keyboard with its keyboard key. A note with nothing typed is not kept.

## Read and change a note

1. Tap the note in the list. It opens to read, without the keyboard.
2. To change it, tap the text where you want to type: the keyboard comes up.
3. Go back to the list when you are done; the changes are saved.

## Delete a note

1. Open the note.
2. Tap the bin at the top right.
3. Tap **Delete note** to confirm, or **Cancel** to keep it.

Deleting all the text of a note also deletes the note.

Notes stay on the phone when it restarts and when its software is updated. They are plain
text: no formatting, pictures or checklists, and there is no search yet.
