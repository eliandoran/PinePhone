The interface's log is kept across restarts, the last five, and tells each call's course (how it started, what you did, how it ended and the network's reason), so a problem can still be looked into after the phone restarted. USB file transfer shows them in a read-only **Logs** folder, and **Settings › Developer mode › Log modem commands** adds everything the phone and the modem say to each other: <https://eliandoran.github.io/PinePhone/debugging/#what-to-look-at>.
